# Palani Kumar — Portfolio

Personal portfolio with scroll-based storytelling, project experience, profile links, and a downloadable resume.

## Files

- `index.html`: content
- `style.css`: styling and responsive layout
- `story.js`: scroll reveal and reading progress
- `Palani_Kumar_Resume.pdf`: downloadable resume

## Local preview

Run `python3 -m http.server 8000` in this directory.

## Free hosting

In GitHub Settings → Pages, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

No build step required. Fonts are loaded from Google Fonts, with local fallback fonts.
